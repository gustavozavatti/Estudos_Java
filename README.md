# 📚 Estudos em Java

Repositório criado para registrar minha evolução nos estudos da linguagem **Java** durante a graduação em Ciência da Computação.

Aqui estão reunidos exercícios, práticas e exemplos desenvolvidos ao longo de um curso de Java, desde os conceitos fundamentais de programação até conteúdos relacionados à orientação a objetos, tratamento de exceções e manipulação de arquivos.

## 📋 Sobre o projeto

Este repositório funciona como um registro da minha evolução na linguagem **Java**, começando pelos conceitos fundamentais de programação e avançando gradualmente para conteúdos mais complexos.

Os conteúdos estão separados em pastas e organizados em uma sequência de estudos, facilitando o acompanhamento da evolução dos conceitos aprendidos e praticados durante o curso.

## 🏗️ Programação orientada a objetos

Durante o curso, são estudados conceitos fundamentais da **Programação Orientada a Objetos (POO)**, utilizados para organizar o código e representar entidades através de classes e objetos.

Entre os conteúdos praticados estão:

- Classes e objetos
- Atributos e métodos
- Construtores
- Encapsulamento
- Sobrecarga de métodos
- Composição
- Enumerações
- Herança
- Polimorfismo
- Classes abstratas
- Sobrescrita de métodos com `@Override`

Esses conceitos ajudam a desenvolver uma compreensão melhor da organização de programas e da reutilização de código em Java.

## ⚙️ Tratamento de exceções e arquivos

O curso também aborda mecanismos para lidar com situações inesperadas durante a execução dos programas e para trabalhar com arquivos.

Entre os conteúdos estudados estão:

- Tratamento de exceções com `try`, `catch` e `finally`
- Utilização de `throw` e `throws`
- Criação de exceções personalizadas
- Leitura de arquivos
- Utilização de classes como `File`, `FileReader` e `BufferedReader`
- Processamento de informações armazenadas em arquivos

Esses recursos permitem desenvolver programas mais preparados para lidar com erros e trabalhar com dados externos.
